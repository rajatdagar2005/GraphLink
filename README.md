# GraphLink

GraphLink is an interactive graph visualization and algorithm simulation platform designed to help users build, explore, and understand graph data structures through real-time visualizations. The application enables users to create custom graphs, manipulate nodes and edges dynamically, and observe graph traversal algorithms step-by-step, making complex concepts easier to learn and analyze.

## 🌐 Live Demo

##  https://graph-link.vercel.app/

## ✨ Features

### 📌 Interactive Graph Creation
- Create nodes dynamically with a simple click.
- Connect nodes using edges to build custom graphs.
- Drag and reposition nodes freely.
- Real-time graph rendering and updates.

### 🔍 Graph Traversal Visualizations
- Breadth First Search (BFS) animation.
- Depth First Search (DFS) animation.
- Step-by-step traversal highlighting.
- Visual representation of node visiting order.

### 🛣️ Shortest Path Finder
- Calculate shortest paths between nodes.
- Highlight discovered paths visually.
- Instant algorithm execution feedback.

### 🎨 User Experience
- Responsive and intuitive interface.
- Smooth drag-and-drop interactions.
- Clean graph visualization layout.
- Optimized rendering performance.

## 🧠 Algorithms Implemented

### Breadth First Search (BFS)
Explores neighboring nodes level-by-level and is commonly used for shortest-path discovery in unweighted graphs.

### Depth First Search (DFS)
Traverses a graph by exploring as far as possible along each branch before backtracking.

### Shortest Path Finder
Computes the shortest route between selected nodes and visually highlights the resulting path.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/rajatdagar2005/GraphLink.git
```

### Navigate to Project Directory

```bash
cd GraphLink
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
